# Zomato Restaurant Data Analysis Using MySQL

## Project Overview

This project focuses on analyzing Zomato restaurant data using MySQL to identify business insights related to restaurant distribution, customer ratings, pricing trends, cuisines, and online delivery services.

The analysis uses SQL queries to explore restaurant performance and understand customer preferences across different cities.

## Project Objectives

* Analyze restaurant distribution across cities.
* Identify highly rated restaurants.
* Understand restaurant pricing patterns.
* Analyze online delivery and table booking services.
* Identify popular cuisine combinations.
* Compare restaurant performance across cities.

## Dataset Description

The dataset contains restaurant-related information, including:

* Restaurant Name
* City
* Aggregate Rating
* Votes
* Cuisines
* Price Range
* Average Cost for Two
* Online Delivery Availability
* Table Booking Availability

## Tools & Technologies

* MySQL
* SQL
* MySQL Workbench

## SQL Concepts Used

* SELECT and WHERE
* DISTINCT
* GROUP BY and HAVING
* ORDER BY and LIMIT
* Aggregate Functions (COUNT, SUM, AVG)
* Subqueries
* Common Table Expressions (CTEs)
* Window Functions (ROW_NUMBER, RANK)

## Key Business Insights

The analysis focuses on four major areas:

1. **Restaurant Distribution:** Identifying cities with the highest restaurant concentration.
2. **Customer Ratings:** Understanding customer satisfaction through restaurant ratings.
3. **Pricing Analysis:** Comparing restaurant pricing segments and their average ratings.
